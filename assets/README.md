# Assets

Copies of OCW files the Build Diary uses; the originals stay in
[OCW](https://github.com/newkit/OCW), where the app uses them.

| File | From OCW | Licence |
|---|---|---|
| `logos/ocw.svg`, `logos/ocw-512.png` | `artwork/logos/` (the app logo) | MIT OR Apache-2.0, like OCW's code |
| `fonts/FiraMono-Regular.ttf` | `crates/ocw-render/assets/fonts/` (the app's UI font; used for clocks, counters, the commit log and badges) | SIL Open Font License 1.1, [`fonts/OFL.txt`](fonts/OFL.txt); © 2012-2015 The Mozilla Foundation and Telefonica S.A. |

Lato (titles and captions) comes from the system (`fonts-lato` on Debian).
